Put your posters and videos here. That is all.

On GitHub: open this folder (assets/creative), click a sub-folder (or make a new one), then
Add file > Upload files, drop your photos in, and press Commit changes.
About a minute later they appear on the creative page. Nothing else to run or edit.

Sub-folders are the filter tabs on the page: CHiPSET, SRM-placements, Reels, anything you create.
A video can have a cover picture: upload an image with the same name next to it (promo.mp4 and promo.jpg).
To set your own title for a file, add a line to titles.txt:   file name = Title
Keep each video under about 25 MB.

(The old way still works too: python3 tools/build-creative-list.py)
